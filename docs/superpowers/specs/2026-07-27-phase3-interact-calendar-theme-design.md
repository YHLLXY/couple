# 阶段 3：互动增强 — 设计文档

> 文档版本：v1.0 | 日期：2026-07-27 | 项目：小甜豆

---

## 一、目标

实现互动广场、甜蜜日历、主题切换 UI。三个模块独立，core/ 零改动。

---

## 二、决策

| 决策 | 结论 |
|------|------|
| 互动形式 | 独立互动广场（签到 + 贴纸墙 + 动态流），不在心愿卡片上加互动按钮 |
| 日历深度 | 月历 + 纪念日倒计时 + 心愿/签到联动 |
| 主题切换 | `/settings` 设置页 + 「我的」页面快捷轮换 |
| core/ | 不改 |

## 三、模块设计

### 3.1 interact — 互动广场

**页面：** InteractHome.vue 重写

**布局（从上到下）：**
1. **签到区** — "今天也想你"大按钮，点击签到，签到后按钮变灰+对勾。显示连续签到天数。
2. **贴纸墙** — 3×N 网格展示所有贴纸，点击贴纸后贴纸从下往上飘 800ms 动画，同时记录到互动动态。
3. **互动动态** — 按时间倒序展示最近的互动记录（签到、贴纸），每条显示时间 + 内容。

**Store 增强：**
- `checkInToday` → 从布尔改为日期字符串，支持"连续签到 N 天"计算
- 新增 `activityLog: { type, content, time }[]` 动态记录
- `addSticker(stickerId)` — 记录贴纸使用 + 触发浮动动画
- localStorage 持久化签到日期和动态记录

### 3.2 calendar — 甜蜜日历

**页面：** CalendarHome.vue 重写

**布局（从上到下）：**
1. **纪念日倒计时卡片** — 顶部轮播/卡片展示"距 X 纪念日还有 N 天"，7 天内高亮。无纪念日时不显示。
2. **月历组件** — 自绘月历网格（7 列 × 5-6 行），显示当月日期。每天小格内用颜色圆点标记：
   - 🟢 绿色：双方都签到
   - 🔴 粉色：有未完成心愿
   - 🟡 黄色：当天有纪念日
3. **底部图例** — 三色圆点说明
4. **点击某天** → 弹出详情（Vant Popup）：当日心愿列表 + 签到状态 + 纪念日信息

**月历组件自绘**（不引入第三方日历库）：
- 计算当月第一天是星期几
- 计算当月总天数
- CSS Grid 7 列布局
- 上月/下月切换箭头
- Mock 纪念日数据（在一起纪念日、第一次旅行等）

**Store 增强：**
- `selectedMonth` — 当前展示的年月
- `getMonthData(year, month)` — 获取某月每日标记数据
- `addAnniversary / removeAnniversary` — 已有
- Mock 纪念日种子数据

**跨 Store 联动：**
- 读取 wish store 的心愿日期
- 读取 interact store 的签到日期
- 计算每日标记颜色

### 3.3 theme — 设置页 + 快捷切换

**新建：/settings 页面**
- 路径：`/settings`（已有路由占位，复用）
- 内容：
  1. **主题选择** — 3 个主题色卡（🍓草莓粉 / 🫐蓝莓蓝 / 🍋柠檬黄），点击切换，当前选中高亮
  2. **通知设置** — 浏览器推送开关
  3. **关于** — 版本号、项目信息

**改造 UserHome.vue：**
- 在菜单列表顶部加一行主题快捷切换：点击直接轮换到下一个主题，旁边显示当前主题名

**Store：** 不改，已有 `setTheme()` 方法。
